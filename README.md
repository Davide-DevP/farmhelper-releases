# Farm Helper - release

Solo i jar della mod **Farm Helper** per Fabric (Minecraft 26.2). Il codice sorgente non e' qui.

- Installazione: scarica `farmhelper-<versione>.jar` dall'ultima release e copialo nella cartella `mods` dell'istanza
  (servono Fabric API e Fabric Language Kotlin). Togli le versioni precedenti.
- Aggiornamenti: la mod controlla questo repository all'ingresso nel mondo e si aggiorna da sola
  (`/farmhelper update`); il jar nuovo viene installato alla chiusura del gioco.
